# NÜMA — Frecuencia del Ser ✦ Plataforma Web de Bienestar y Lujo Espiritual

> *“Más que una marca. Una frecuencia.”*  
> *“Vuelve a ti.”*

Plataforma web boutique diseñada y desarrollada para **NÜMA**, marca mexicana de bienestar sensorial, rituales botánicos, numerología transpersonal y sonoterapia con cuencos.

---

## ✦ Identidad Visual & Diseño
- **Paleta de Color Oficial**:
  - Negro Elegante (`#0A0A0A` / `#111111`)
  - Dorado Brillante (`#FFD700` / `#FFE57F`)
  - Oro Profundo (`#B8860B`)
  - Beige Suave (`#EDE0C9` / `#FAF6EE`)
- **Tipografía Editorial**: `Cinzel`, `Playfair Display`, `Cormorant Garamond` y `Montserrat`.
- **Efectos Visuales**: Canvas de partículas de polvo estelar dorado con interactividad sutil, halos lumínicos y animaciones de transición refinadas sin sobrecarga visual.

## ✦ Arquitectura & Módulos

### 1. Home & Hero Cinematográfico
- Logotipo oficial e identidad NÜMA.
- Frase insignia: *“Vuelve a ti. Un espacio para conectar con tu esencia a través de experiencias, rituales y herramientas de bienestar.”*
- Llamados a la acción duales: *Descubrir NÜMA* y *Explorar Tienda*.

### 2. ¿Qué es NÜMA? (Sección Editorial)
- *“Más que una marca. Una frecuencia.”*
- 5 pilares interactivos con iconografía dorada minimalista: **Conciencia, Energía, Equilibrio, Transformación, Esencia**.

### 3. Experiencias & Terapias (Arquitectura Modular y Extensible)
- **Numerología Transpersonal**: Sesiones individuales, de pareja y lectura de año personal.
- **Cuencos / Sonoterapia**: Inmersiones individuales, círculos grupales y sesiones binaurales.
- **Arquitectura Extensible**: Slots preparados para futuras disciplinas (`[NUEVA EXPERIENCIA]`, `[NUEVA TERAPIA]`, `[NUEVO RITUAL]`) como Breathwork, Círculos de Luna y Retiros de Silencio.

### 4. Tienda E-Commerce Integrada (Mobile-First)
- Colecciones: **Velas, Jabones, Aromas, Difusores, Baño y Relajación, Kits NÜMA**.
- Tarjetas con pirámide olfativa (Salida, Corazón, Fondo), precio en MXN, stock y botón agregar al carrito.
- Modal **Quick View** con detalles ampliados y selector de variantes.

### 5. Rituales NÜMA & Guía de Respiración Interactiva
- Desglose de los 5 Rituales: *Calma, Energía, Intención, Equilibrio, Descanso*.
- Cada ritual incluye su sinergia de vela + aroma + jabón + sonido.
- **Temporizador interactivo de respiración consciente guiada** (Inhala, Sostén, Exhala) con halo áureo pulsante.

### 6. Numerología Interactiva en Vivo
- Didáctica de los 4 conceptos: *Camino de Vida, Número del Alma, Número de Expresión, Año Personal*.
- **Calculadora en Vivo**: Ingresa fecha de nacimiento y nombre → calcula al instante el Camino de Vida (respetando números maestros 11, 22, 33), el Año Personal y despliega el arquetipo con su mantra, frecuencia y ritual sugerido.

### 7. Cuencos y Sonoterapia
- Sección audiovisual: *“El sonido también puede convertirse en un ritual.”*
- **Reproductor de audio de alta fidelidad** integrado con audio real de cuencos y osciloscopio visual animado con barras doradas.

### 8. Journal NÜMA
- Artículos editoriales sobre Trataka, ondas cerebrales Alfa/Theta, ciclos de 9 años y memoria olfativa.
- Modal de lectura inmersiva con formato editorial.

### 9. Storytelling & Manifiesto NÜMA
- Historia, filosofía, significado de *Frecuencia del Ser* y el Manifiesto completo extraído del manual corporativo.

### 10. Sistema de Reservas en 4 Pasos
- Wizard interactivo: Selección de Servicio → Modalidad (Online / Presencial) → Calendario de Fechas y Horarios → Datos del Consultante → Generación de folio único `#RES-XXXXX` y enlace directo para sincronizar con WhatsApp a `@frecuencia_numa`.

### 11. E-Commerce Funcional (Off-Canvas Drawer & Checkout)
- Carrito lateral deslizable con cálculo dinámico de subtotales.
- Barra de progreso para envío gratis ($1,200 MXN).
- Cupón de descuento funcional (`NUMAFRECUENCIA` = 15% OFF).
- Modal de checkout con selección de método de pago (Tarjeta, SPEI, PayPal), folio de pedido `#NUM-XXXXXX` y persistencia en `localStorage`.

### 12. Contacto & Redes
- Canales directos a Instagram `@frecuencia_numa`, WhatsApp oficial, correo y estudio en CDMX.
- Hashtag: `#FrecuenciaDelSer`.

## ✦ Tecnologías Utilizadas
- **HTML5 Semántico**: Estructura accesible y optimizada para SEO.
- **Vanilla CSS3 Moderno**: Custom properties, CSS Grid, Flexbox, backdrop-filter blur y animaciones a 60fps.
- **JavaScript Moderno (ES6+ Modules)**: Arquitectura desacoplada, reactividad ligera y 0 frameworks pesados innecesarios.
- **Vite 6**: Bundler y entorno de desarrollo ultra veloz.

## ✦ Desarrollo Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build

# 4. Previsualizar compilación
npm run preview
```
