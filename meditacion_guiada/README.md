# Carpeta de Música: Meditación Guiada NÜMA
Ruta: `assets/audio/meditacion_guiada/`

Coloca aquí los archivos de audio de las meditaciones guiadas (en formato `.mp3` o `.wav`).

### Pistas preconfiguradas en el sistema:
1. `retorno_al_ser.mp3` — Retorno al Ser (432 Hz)
2. `apertura_corazon.mp3` — Apertura del Chakra Corazón (528 Hz)
3. `claridad_proposito.mp3` — Claridad & Propósito de Vida (741 Hz)
4. `sueno_profundo.mp3` — Quietud Nocturna & Sueño Reparador (396 Hz)

*Nota:* Si añades canciones con otros nombres, puedes registrarlas fácilmente en `src/data/meditaciones.js`.
Mientras se agregan los archivos definitivos, el reproductor inteligente cuenta con fallback automático a la composición insignia en 432 Hz para garantizar reproducción continua sin errores.
